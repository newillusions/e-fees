## What's new

- **Marking a project as Awarded now sets up its folders for you.** The project folder moves from 01 RFPs to 11 Current, and any 00 Design Folders content is merged into the existing structure without overwriting files already there. Files named in the yy-cccnn pattern are renamed to match the project (#70).
- **Folder problems are now shown, not hidden.** If a folder could not be moved, merged or renamed, the app tells you what failed instead of carrying on silently (#70).
