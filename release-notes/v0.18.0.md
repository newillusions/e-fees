## What's new

- **Bulk actions on projects are more reliable.** Selecting multiple projects and applying a bulk status change now logs the activity correctly, updates the list immediately, and shows a clear warning if only some of the selected projects could be updated.
- **Marking projects as Lost now moves their folder automatically.** Bulk-setting a project's status to Lost relocates its project folder into "00 Inactive" and triggers a Nextcloud rescan, so the folder structure stays in sync without a manual step.
- **Company, Contact, and Proposal lists refresh correctly** after edits, and folder-path drift between the app and disk now self-heals.
- **Dashboard failures are visible instead of silent.** If dashboard stats fail to load, you'll now see an error banner with a retry option instead of a blank or stale screen.
- **"Preliminaries" removed from the default stage list** in fee pricing - it's no longer offered as an autocomplete suggestion when adding stages.
