## What's new

- **Proposal PDFs now render through a production document service.** Fee records generate through a new fp-template + gotenberg rendering path (PRs #47, #49), with production rendering routed to a dedicated remote docbuilder service (#50) instead of the desktop app doing the work locally.
- **Payment terms now state invoices are submitted with each stage's deliverable**, per the current owner-approved wording, applied consistently across the clause catalog (#51).
- **Project merge and folder reconciliation.** Projects can now be merged with cascade-delete of the losing record (#35), and on-disk project folders reconcile automatically after a merge or cascade-delete, including a backup-cleanup action (#36, #37).
- **Fee revisions are real.** Creating a second revision of a fee now works correctly end to end, with historical revisions backfilled (#46).
- **New per-client win-ratio report** for comparing proposal win rates across clients (#45).
- **Historical fee-data backfill**: pricing totals and stage/outcome data loaded from the archive corpus into the database (#39, #40, #41, #42, #43, #44).
- **Update dialog now shows the correct current-to-new version** instead of repeating the target version twice (#34).
- **Clause corpus gap closed**, adding 3 previously-missing fee proposals to the searchable archive (#38).

## Security and hardening

- **Removed a hardcoded scope-service API key and internal IPs baked into every release build.** The desktop app now receives its scope-service credentials at build time instead (#55).
- **Fixed a SQL-injection-shaped identifier interpolation** in e-fees-api and e-fees-scope, restricted CORS from allowing any origin, and switched API-key comparison to constant-time (#55).
- **CI hardened to the workspace Forgejo Actions standard** (#54).
- **Retired the dead Playwright end-to-end test stack**, which never ran; `e2e-mcp/` (Tauri MCP) remains the only live E2E path (#56).

## Infrastructure

- **e-fees-api and e-fees-scope containers now follow Unraid's PUID/PGID convention**, running as an unprivileged user by default instead of a hardcoded uid, with the Nextcloud SSH key copied to a scratch directory so folder export keeps working under the new user (#53).
