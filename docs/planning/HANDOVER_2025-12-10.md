## Work Completed This Session

### 1. Folder Sync "Update DB" Fix (from previous session continuation)
**Problem**: "Update DB" action was failing with error:
```
Found NONE for field `area`, with record `projects:⟨22_96603⟩`, but expected a string
```

**Root Cause**: ORM-style `.merge().await` tries to deserialize the full Project record after update, but some projects have NULL values for optional fields (like `area`) while the Rust struct expects `String`.

**Solution**: Implemented raw SQL UPDATE that only updates the `status` field without deserializing the result:
- Added `execute_raw_query()` method to `DatabaseManager` in `src-tauri/src/db/mod.rs`
- Modified `resolve_folder_inconsistency()` in `src-tauri/src/commands/folder_sync.rs` to use raw SQL

```rust
// Raw SQL avoids deserialization issues with NULL fields
let query = format!(
    "UPDATE projects:`{}` SET status = '{}', time.updated_at = time::now()",
    project_id,
    escaped_status
);
manager_clone.execute_raw_query(&query).await
```

### 2. Activity Logging for Folder Sync
**File Modified**: `src/lib/components/FolderSyncModal.svelte`

Added activity logging after each successful folder sync resolution:
- `update_db` → logged as `status_change` with old/new status values
- `move_folder` → logged as `update` with folder movement description
- `create_folder` → logged as `create` with folder creation description
- `ignore` → logged as `update` with ignore description

Each log entry includes metadata:
- `source: 'folder_sync'`
- `action_type`: the resolution action taken
- `inconsistency_type`: wrong_location, missing, orphan, duplicate
- `actual_path` / `expected_path`: file system paths

### 3. Store Refresh After Database Update
**File Modified**: `src/lib/components/FolderSyncModal.svelte`

Added `projectsActions.refresh()` call after successful `update_db` action to ensure the Projects list view reflects the updated status immediately.

```typescript
// Refresh projects store to reflect DB changes in the UI
if (action === 'update_db') {
  await projectsActions.refresh();
}
```
