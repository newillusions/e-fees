### Priority 1: UI/UX Fixes

#### 1. Top Bar Button Functionality
- **Search button** (next to settings): Currently does nothing - needs implementation
- **Alarm/notification button**: Currently does nothing - needs implementation

#### 2. Activity Log System
- **Issue**: Dashboard "Recent Activity" panel is empty
- **Solution**: Create `activity_log` table in SurrealDB to track all actions
- **Events to log**:
  - Project status changes (completed, revised, etc.)
  - Fee proposal status changes
  - CRUD operations on key entities

## Database Schema Addition Needed

### Activity Log Table (Proposed)
```sql
DEFINE TABLE activity_log SCHEMAFULL;
DEFINE FIELD action ON activity_log TYPE string;        -- "status_change", "create", "update", "delete"
DEFINE FIELD entity_type ON activity_log TYPE string;   -- "project", "fee", "company", "contact"
DEFINE FIELD entity_id ON activity_log TYPE string;
DEFINE FIELD entity_name ON activity_log TYPE string;
DEFINE FIELD old_value ON activity_log TYPE option<string>;
DEFINE FIELD new_value ON activity_log TYPE option<string>;
DEFINE FIELD user ON activity_log TYPE string;
DEFINE FIELD timestamp ON activity_log TYPE datetime DEFAULT time::now();
DEFINE FIELD metadata ON activity_log TYPE option<object>;

DEFINE INDEX activity_log_timestamp ON activity_log FIELDS timestamp;
DEFINE INDEX activity_log_entity ON activity_log FIELDS entity_type, entity_id;
```
